# Read aloud

1. Write the spoken text for your last reply by the rules in `read-aloud.md`, two folders above this file.
2. Speak it: run `C:/Users/Alex/.venv/Scripts/python.exe <plugin folder>/speak.py "<spoken text>"`, the plugin folder being two folders above this file.

The speaker says the text in the newest gpt-realtime voice LiteLLM serves, on Windows' default output. Say nothing else about it in the reply.
